## 🧠 About the Mission

**Code Crusade** is my personal Python learning journey, where I practice programming concepts, solve problems, debug errors, and build my problem-solving skills one day at a time.

This repository documents my progress from beginner fundamentals to more advanced programming concepts. Every script represents practice, experimentation, and a lesson learned.

> *The goal isn't to write perfect code on day one. The goal is to become better with every line of code.*

## 🎯 Mission Objectives

- 🐍 Strengthen Python fundamentals.
- 🧩 Improve logical thinking and problem-solving.
- 🔄 Master loops, conditions, strings, and data structures.
- 🛠️ Build small programs through hands-on practice.
- 📈 Track daily progress and maintain consistency.
- 🚀 Progress toward real-world projects and development.

## ⚡ Run the Programs

**1. Clone the repository**

```bash
git clone https://github.com/Prakulyadav/Codecrusade.git
```

**2. Open the project folder**

```bash
cd Codecrusade
```

**3. Run any Python file**

```bash
python Day1.py
```

Replace `Day1.py` with the name of the program you want to run. Make sure Python is installed on your computer.
